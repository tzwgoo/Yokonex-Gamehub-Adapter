# VRChat OSC 联动

无需安装游戏内 Mod。GameHub 通过 VRChat 桌面版的 OSC 输出接收 Avatar 参数，再按规则驱动本地设备。

## 安装

1. 安装并启动 **Yokonex GameHub**。
2. 打开 **插件中心 → 线上市场**，安装 **VRChat** 插件。
3. 返回 **插件中心 → 游戏联动**，确认已经出现 **VRChat** 卡片。
4. 在 **设备 / 蓝牙** 中连接设备，并准备需要使用的波形。

> 当前插件只监听本机 `127.0.0.1`。VRChat 与 GameHub 必须在同一台电脑运行。本插件不会修改 VRChat 游戏文件。

## 开启 VRChat OSC

1. 启动 VRChat 并进入任意世界。
2. 打开圆盘菜单 **Action Menu**。
3. 依次选择 **OSC → Enabled**。

默认情况下，VRChat 把 Avatar 参数发送到本机 UDP `9001` 端口。GameHub 默认监听同一个端口，不需要在游戏中另外设置。

## 配置联动

1. 在 **插件中心 → 游戏联动** 找到 **VRChat**。
2. 打开卡片上的总开关，再点击 **配置**。
3. 保持 **OSC 端口** 为 `9001`。
4. 选择默认输出通道和输出设备。
5. 配置参数规则：
   - 可以直接启用内置规则。内置规则默认关闭。
   - 自定义规则必须填写唯一的 **规则 ID**。
   - **参数名**填写 OSC 地址 `/avatar/parameters/` 后面的名称，例如 `VelocityZ`。
   - 选择条件、阈值、动作、波形、强度、通道和持续时间。
6. 点击 **保存配置**。正常启动后，状态会显示 `OSC 监听 127.0.0.1:9001`。

## 验证

1. 先在配置页点击 **测试触发**，确认设备和波形可以正常工作。
2. 保持 GameHub 和 VRChat 运行，并使用会改变 Avatar 参数的移动、手势或表情。
3. 等待几秒后重新打开配置页，在底部查看 **最近参数**。
4. 用最近参数中的名称创建或调整规则。
5. 规则命中后，卡片触发次数会增加，设备会执行对应动作。

## Chatbox 回传

开启后，GameHub 会向 VRChat 默认输入端口 `9000` 发送状态文字。

模板支持：`{a}`、`{b}`、`{a_raw}`、`{b_raw}`、`{param}`、`{value}`。

## 修改 OSC 端口

只有 `9001` 被其他 OSC 软件占用时才需要修改。

1. 在 GameHub 中把 **OSC 端口**改为新的端口，例如 `9011`。
2. 在 Steam 中打开 **VRChat → 属性 → 通用 → 启动选项**。
3. 填入：

   ```text
   --osc=9000:127.0.0.1:9011
   ```

4. 重启 VRChat，再确认 GameHub 状态显示新的监听端口。

启动参数格式为 `--osc=VRChat输入端口:发送地址:VRChat输出端口`。最后一个端口必须与 GameHub 的 OSC 端口一致。

## 常见问题

**游戏联动中找不到 VRChat**

先到 **插件中心 → 线上市场**安装 VRChat 插件，再返回游戏联动页面。

**状态显示端口不可用**

关闭正在监听该端口的 OSC 软件。也可以按上面的步骤同时修改 GameHub 监听端口和 VRChat 启动参数。

**最近参数为空**

确认 VRChat 中 **OSC → Enabled** 已开启，并让当前 Avatar 产生移动、手势或表情变化。自定义参数必须存在于当前 Avatar。

**有参数但设备没有动作**

依次检查规则开关、参数名、条件、阈值、冷却时间、设备连接和波形设置。先用 **测试触发** 排除设备链路问题。
