# VRChat OSC 联动

无需安装游戏内 Mod。Yokonex GameHub 在本机监听 VRChat 的 Avatar OSC 参数，命中规则后直接驱动本地设备波形与强度层（不走 IM `commandId` 游戏事件通道）。

## 安装 / 前置

1. 安装并启动 **Yokonex-Gamehub**。
2. 安装 **VRChat**，并在游戏中开启 OSC：
   - 打开 Action Menu → Options → OSC → **Enabled**
   - 确认发送端口为默认（Avatar 参数发往本机 **9001**，与 GameHub 默认监听一致）
3. 如需设备输出：在 GameHub「设备 / 蓝牙」页连接设备，并在波形库中准备好要用的波形。

> 本联动不向游戏目录写入任何文件；关闭 GameHub 或停用联动即停止监听。

## 配置

1. 启动 Yokonex-Gamehub。
2. 打开 **插件中心 → 游戏联动**。
3. 找到 **VRChat** 卡片：
   - 打开总开关以启用 OSC 监听
   - 点击 **配置** 进入规则页
4. 在配置中设置：
   - **OSC 端口**：默认 `9001`（需与 VRChat 发送目标一致）
   - **全局冷却**：同一规则最短触发间隔，避免参数抖动刷屏
   - **默认通道 / 设备**：规则未单独指定时使用
   - **参数规则**：为 Avatar 参数添加条件与动作
5. 每条规则建议填写：
   - **规则 ID**（稳定唯一，便于保存）
   - **参数名**（如 `VelocityZ`、自定义 Avatar 参数名）
   - **条件**：大于 / 小于 / 等于 / 不等于 / 变化
   - **阈值**（数值条件时使用）
   - **动作**：设置强度并播放 / 临时强度后恢复 / 仅调整强度 / 调整强度并播放
   - **波形**、**强度**、**通道**、**持续时间**
6. 保存配置。启用后状态应显示类似 `OSC 监听 127.0.0.1:9001`。

### Chatbox（可选）

开启 Chatbox 回传后，GameHub 会按模板向 VRChat Chatbox 端口（默认 **9000**）发送状态文字。
模板可用占位符：`{a}` `{b}` `{a_raw}` `{b_raw}` `{param}` `{value}`。

## 验证

1. 保持 GameHub 运行，VRChat 进入带 OSC 参数的 Avatar。
2. 触发会改变参数的动作（移动、表情、PhysBone、世界交互等）。
3. 在 VRChat 卡片状态或配置页底部「最近参数」中应能看到参数名与数值。
4. 命中规则时：
   - 触发次数增加
   - 已连接设备应有对应波形 / 强度变化
5. 可使用配置页 **测试触发** 先验证波形链路，再排查 OSC 参数名是否写对。

## 与其它联动的关系

- VRChat 与键盘、响度、数位板等共用 **多源强度层**：同一通道取 **最大值**，不相加。
- 本联动输出走本地蓝牙 / 设备管道；**不会**自动向役次元 IM 发送 `game_cmd`。
- 若需要同时推远程指令，请使用带 `commandId` 的游戏 Mod 联动，或自行对接外部插件 SDK。

## 常见问题

**状态显示端口不可用**
本机 9001 已被占用。关闭其它 OSC 工具，或在配置中改 OSC 端口并与 VRChat 侧一致。

**最近参数一直为空**
确认 VRChat OSC 已启用；进入带参数的 Avatar；部分世界或 Avatar 不发送你监听的参数名。参数名需与 Avatar 实际 OSC 地址最后一段一致（`/avatar/parameters/<名称>`）。

**有参数但没有电击 / 波形**
检查规则是否启用、条件与阈值是否匹配、冷却是否过短被跳过；设备是否已连接；规则中是否选择了有效波形。

**启用后影响其它软件**
GameHub 只监听本机 UDP 端口，不注入 VRChat 进程。停用联动或关闭 GameHub 即可释放端口。

**需要更多插件 / 自写逻辑**
可参考外部插件 WebSocket SDK（`docs/external-plugin-sdk.md`），用独立进程接入同一强度管道。
