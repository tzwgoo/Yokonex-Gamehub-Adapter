# Balatro 接入说明

支持 Steam 版 Balatro，依赖 Lovely 和 Steamodded 1.0+。

1. 按 [Steamodded Windows 安装说明](https://github.com/Steamodded/smods/wiki/Installing-Steamodded-windows) 安装 Lovely 与 Steamodded。
2. 在 GameHub 市场安装本插件。
3. 双击 `一键安装.bat`。
4. 先启动 GameHub，再启动 Balatro。

事件日志位于 `%APPDATA%\Balatro\yokonex_events.log`。卸载时删除 `%APPDATA%\Balatro\Mods\YokonexGameHub`。
