# 星际争霸 II 接入说明

本插件只检测 Windows 上《星际争霸 II》的运行状态，不读取、解析或生成 `.SC2Replay`。

## 使用方法

1. 在 GameHub 插件市场安装并启用“星际争霸 II”。
2. 保持 GameHub 运行，然后通过 Battle.net 启动游戏。
3. 在游戏联动页面配置以下事件：
   - 游戏启动
   - 进入游戏前台
   - 切到游戏后台
   - 游戏退出

无需修改游戏文件，也不需要管理员权限。

## 事件边界

普通天梯没有可供外部插件读取的官方实时战斗日志。因此本插件不能可靠识别对局开始、造兵、单位受损或胜负，也不会用窗口画面或录像猜测这些事件。

插件识别的进程名为 `SC2_x64.exe` 和 `SC2.exe`。如果游戏更新后进程名发生变化，需要同步更新插件。
