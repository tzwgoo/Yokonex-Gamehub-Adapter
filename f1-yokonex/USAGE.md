# F1 24 / F1 25 接入说明

PC、PlayStation 和 Xbox 都能发送 UDP；GameHub 桥接器运行在 Windows。

在游戏的“设置 → 遥测设置”中填写：

- UDP 遥测：开启
- UDP IP 地址：运行 GameHub 电脑的 IP；同一台电脑填 `127.0.0.1`
- UDP 端口：`20777`
- UDP 格式：F1 24 选 `2024`，F1 25 选 `2025` 或兼容的 `2024`
- UDP 发送频率：任意

先启动 GameHub，再启动游戏。桥接器只处理事件包，不保存连续车辆遥测。

如果端口被 SimHub 等软件占用，请让该软件把 UDP 转发到 `20777`，或用环境变量 `F1_UDP_PORT` 配置其他端口。
