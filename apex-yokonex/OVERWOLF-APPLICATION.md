# Overwolf 开发者申请说明

## 申请步骤

1. 打开 Overwolf 的 “Phase 1 - App Idea to Submission” 页面。
2. 创建或登录 Overwolf 账号。
3. 点击页面中的 “submit your proposal” 提交 App 提案。
4. App 类型选择公开 App，不要填写为私人后台桥接工具。
5. 等待 DevRel 审核；通过后账号会获得未发布 App 的加载权限。
6. 使用开发版 Overwolf 加载本目录，完成 Apex 实机测试。
7. 准备 OPK、隐私政策、使用条款、商店图片和应用说明。
8. 提交 QA；通过后在 Developer Console 发布 Testing 或 Production 版本。

## 推荐填写内容

- App name: `Yokonex Apex Link`
- Supported game: `Apex Legends`
- Framework: `Overwolf Native`
- App type: `Public`
- Core value: `A visible companion app that turns supported Apex Legends live game events into configurable, output-only feedback through Yokonex-Gamehub.`
- Public-facing UI: `A desktop status window showing game detection, gateway connection, local player and sent-event count.`
- Data source: `Overwolf Game Events Provider only.`
- Safety: `No memory reading, process injection, overlays that reveal hidden information, input automation, macros, recoil control or gameplay modification.`
- Monetization: 按 Overwolf 当前要求填写 Overwolf Ads 或 Subscription 计划，不要填写第三方广告。

## 建议英文说明

`Yokonex Apex Link is a public companion app for Apex Legends. It receives only supported Overwolf GEP events and forwards user-configured event identifiers to the local Yokonex-Gamehub application, which can provide output-only IM or Bluetooth feedback. The app has a visible desktop status window and does not read game memory, inject code, automate input, control recoil, expose hidden game information, or provide a competitive advantage.`
