# 杀戮尖塔接入说明

依赖 ModTheSpire、BaseMod 和 CommunicationMod。

1. 在 Steam 创意工坊安装并启用 ModTheSpire 与 BaseMod。
2. 在 GameHub 市场安装本插件。
3. 双击 `一键安装.bat`，它会安装 CommunicationMod 并写入通信配置。
4. 通过“Play With Mods”启动游戏，启用 BaseMod 和 CommunicationMod。

CommunicationMod 使用 MIT 许可，来源和校验信息见 `THIRD-PARTY-NOTICES.md`。本适配器只读取状态，不会替玩家出牌或选择路线。
