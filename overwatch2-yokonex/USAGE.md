# 守望先锋 2 视觉联动

## 使用条件

- Windows 10 或 Windows 11。
- 游戏分辨率为 1920×1080、2560×1440 或 3840×2160，画面比例为 16:9。
- 显示模式选择“无边框窗口”。
- 使用游戏默认 HUD 布局，玩家血条或数字血量位于左下区域。

## 使用步骤

1. 在 GameHub 插件市场安装“守望先锋 2”。
2. 打开“联动”，配置六个血量事件的指令和波形。
3. 启用游戏联动。
4. 启动《守望先锋 2》，进入训练场或对局。
5. 保持游戏窗口位于前台。识别器只处理前台游戏画面。

## 支持事件

- 玩家受到伤害、恢复生命。
- 生命值低于 35%、低于 15%。
- 生命值耗尽、从耗尽状态恢复。

## 纯数字血量

- 支持 1～4 位整数，不支持小数、百分号和图标。
- 只有数字时也能判断掉血、回血、归零和恢复。
- 如需低血量和危险事件，请在 `vision.json` 中设置 `numericMaxHealth`；`0` 表示最大血量未知。
- 其他游戏可调整归一化坐标 `numericRoi`，同一配置自动适配 1080p、2K 和 4K。

## 限制

- 首版只识别玩家左下 HUD，不识别胜利、失败或击杀文字。
- 自定义 HUD 缩放、色盲滤镜、非 16:9 分辨率可能降低准确率。
- 游戏窗口被其他窗口遮挡时不会识别。
- 模型需要连续三帧确认，事件通常有约 0.4～0.8 秒延迟。
